This application was for a final project submission in my Microsoft Software and Systems Academy (MSSA) Cloud Application Development cohort.

The intent of the project was to explore full-stack development, with use of a RESTful API and MVVM / MVC architecture. The API used can be accessed via the following repository:
[Task Tracker RESTful Web API](https://github.com/AaronTigerLee/TaskTrackerWebAPI)
SQLite was used as database to showcase MVC CRUD operations.
